欧几里德算法与扩展欧几里得算法

欧几里得算法

基本思想
用于计算两个整数的​​最大公约数​​。基于原理：
gcd(a,b)=gcd(b,amodb)
重复此过程，直到余数为0。

gcd(a, b):
     while b != 0:
        r = a % b
        a, b = b, r
    return a

示例：计算 gcd(1071, 462)：
1071 ÷ 462 = 2 余 147 → gcd(462, 147)
462 ÷ 147 = 3 余 21 → gcd(147, 21)
147 ÷ 21 = 7 余 0 → ​​gcd = 21​​

扩展欧几里得算法

基本思想
不仅计算 gcd(a, b)，还找到整数 ​​x, y​​ 满足：
a⋅x+b⋅y=gcd(a,b)

gcdext(a,b):
    x0, x1 = 1, 0
    y0, y1 = 0, 1
    while b != 0:
        q = a // b
        r = a % b
        x0, x1 = x1, x0 - q * x1
        y0, y1 = y1, y0 - q * y1
        a, b = b, r
    return (a, x0, y0)

密码学应用:​​计算模逆元​​(常见于RSA求私钥d)
求 a 在模 m 下的逆元，即解：a⋅x≡1(mod m)
等价于：a⋅x+m⋅y=1
用扩展欧几里得算法求 x，即为 a⁻¹ mod m
注：在python库中可以直接调用gcd(a,b)函数与gcdext(a,b)函数。

模运算

基本规则

模运算
加法​
若 a≡b(modn)，则 a+c≡b+c(modn)
减法​
若 a≡b(modn)，则 a−c≡b−c(modn)
乘法​
若 a≡b(modn)，则 a×c≡b×c(modn)
交叉相乘
若a≡b(modp)且c≡d(modp)
则ac≡bd(modp)

费马小定理

定理陈述
如果 p 是素数，且 a 不是 p 的倍数（即 p∤a），则：
a**(p−1)≡1(modp)
证明思路
考虑集合 {a,2a,3a,...,(p−1)a}，在模 p 下，这是一个 1,2,...,p−1的排列。
因此：
a×2a×3a×...×(p−1)a≡1×2×3×...×(p−1)(modp)
由于 (p−1)!与 p 互质，可约去，得证。
应用：计算模逆元
当 p 是素数时，a 在模 p 下的逆元为：
a**(−1)≡a**(p−2)(modp)
示例：3d≡1(mod 13)
d=3(-1)≡3*(11)(mod 13)
d=pow(3,11,13)=9

欧拉定理（费马小定理的推广）

定理陈述
如果 gcd(a,n)=1，则：
a**ϕ(n) ≡1(modn)
其中 ϕ(n)是欧拉函数，表示小于n且与n互质的正整数的个数。
注：在python中可以使用函数invert()求费马小定理逆元

二次剩余

这个文章讲的挺详细的

定义

设整数 a和正整数 m>1，如果存在整数 x使得：
x2≡a(modm)
则称 a是模 m的​​二次剩余​​，否则称 a是模 m的​​二次非剩余​​。
示例
模 7 的二次剩余：
12=1≡1(mod7)✓
22=4≡4(mod7)✓
32=9≡2(mod7)✓
42=16≡2(mod7)✓
52=25≡4(mod7)✓
6**2=36≡1(mod7)✓
所以模 7 的二次剩余为：{1, 2, 4}，二次非剩余为：{3, 5, 6}。

勒让德符号

勒让德符号 (a/p) 表示 a 对模 p 的二次剩余性质。
对于奇素数 p和整数 a，勒让德符号定义为：
(a/p)=
0 如果 p∣a
1 如果 a 是模 p 的二次剩余
-1 如果 a 是模 p 的二次非剩余
性质：
- (ab/p) = (a/p) * (b/p)
- (1/p) = 1
- (-1/p) = (-1)^((p-1)/2)
示例：
(2/7) = 1
(3/7) = -1
(14/7) = 0

-1的二次剩余性质

​​推导​​：
由欧拉准则：pow(-1,(p-1)//2,p)=(-1/p)
因为左边只能是 1 或 -1，模 p下等于右边
​​结论​​：
如果 p≡1(mod4)，则 (−1)(p−1)/2=1，所以 -1 是二次剩余
如果 p≡3(mod4)，则 (−1)(p−1)/2=−1，所以 -1 是二次非剩余

中国剩余定理

中国剩余定理（Chinese Remainder Theorem, CRT）是数论中的一个重要定理，它在密码学、计算机科学等领域有广泛应用。它解决了一组同余方程在模两两互质的整数下的解的存在性和构造问题。

算法：

def crt(a_list, m_list):
    """
    中国剩余定理求解
    a_list: 余数列表 [a1, a2, ..., ak]
    m_list: 模数列表 [m1, m2, ..., mk]（需要两两互质）
    返回: x 满足 x ≡ ai (mod mi) 对于所有i
    """
    from math import prod
    from functools import reduce
    M = prod(m_list)
    for i in range(len(m_list)):
        for j in range(i + 1, len(m_list)):
            if gcd(m_list[i], m_list[j]) != 1:
                raise ValueError(f"模数{m_list[i]}和{m_list[j]}不互质")  
    result = 0
    for i in range(len(m_list)):
        a_i = a_list[i]
        m_i = m_list[i]
        M_i = M // m_i
        t_i = invert(M_i, m_i)      
        result = (result + a_i * M_i * t_i) % M 
    return result
