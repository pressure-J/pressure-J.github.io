pressure-J · 网络空间安全本科生，方向是防御侧。

我在江西财经大学读网络空间安全。日常主要泡在三件事上：应急响应的实战复盘、CTF 的 Web / Misc 题目，以及把学到的原理写成能跑通的笔记。

这个博客是我的知识库出口。写在这里的东西有两个标准：能复现（照着步骤能重跑一遍） 和能讲清（每个动作为什么这么做，而不只是命令）。写不清楚的，说明我还没真的懂。

在做的事

  • 应急响应 / 流量取证

    日志三源关联（认证 + 防火墙 + 审计）、Shiro 反序列化流量还原、Webshell 加密隧道识别。 目标是把一次入侵链完整讲出来，而不是零散地报几个结论。

  • eduSRC 漏洞挖掘

    面向教育行业的 SRC 提交，关注越权、逻辑漏洞与常见组件问题。每个提交都配可复现步骤与截图证据。

  • CTF Agent 工程

    用 Python + FastAPI + LLM 做的自动化解题框架，负责 Agent 核心与 Crypto 工具链， 把解题思路沉淀成可调用的工具。
