Rabin密码

密码学 2026-10-04 2507 字 约 7 分钟
crypto

公钥加密算法（Michael Rabin, 1979），可以理解成"RSA 的平方版"：把 RSA 里的 $e$ 固定成 2，加密就是求平方。

题型识别（看到就用）

  • 题面出现 Rabin 字样，或者"加密算法和某位刺客/名人同名"这种提示
  • 给了 $n$（往往很小、一眼能分解）和密文 $c$
  • 给了一段校验码 / 冗余信息，并说明"放在明文后一起加密""明文与密文长度相同"
  • 最后要求对明文做 md5 提交（说明明文是个数字串而不是直接可读文本）

原理

RSA Rabin
密钥 $n=pq$，$e$ 任意 $n=pq$，$e$ 固定为 2
加密 $c=m^e \bmod n$ $c=m^2 \bmod n$
解密 $\varphi(n)$、$d=e^{-1}$，唯一解 解 $x^2\equiv c \pmod p$ 和 $\pmod q$ 再 CRT
解的数量 1 个 4 个
安全性 依赖大数分解（未被证明等价） 攻破 ⟺ 大数分解，有严格证明

为什么有 4 个根：$n=pq$ 时同余式 $x^2 \equiv c \pmod p$ 有 $\pm r_p$ 两根（$p$ 为奇素数），$\pmod q$ 有 $\pm r_q$ 两根，各取一个用 CRT 组合，共 $2\times 2 = 4$ 个根：

$$x \in { \mathrm{CRT}(r_p, r_q),\ \mathrm{CRT}(r_p, -r_q),\ \mathrm{CRT}(-r_p, r_q),\ \mathrm{CRT}(-r_p, -r_q) }$$

为什么要有校验码：4 个根里解密方也不知道哪个是原文，所以 Rabin 必须额外携带冗余——原文后面拼一段已知的二进制/尾数（本题就是 6 位 110001），四个根里只有一个的尾部对得上。

解题四步

  1. 分解 $n$：小 $n$ 直接 sympy.factorint；$p,q$ 接近用 Fermat；再大用 Pollard rho（本题 $523798549 = 10663 \times 49123$ 秒破）
  2. 模素数开平方：sqrt_mod / 手写 Tonelli–Shanks，得 $r_p, r_q$
  3. CRT 组合出 4 根，此时每个根的平方 $\bmod n$ 都等于 $c$（可作自检）
  4. 用校验码筛：把每个根按校验码的位数/进制切掉尾部，只有一根的尾部与之相符 → 剩下的就是明文

本题实测：

根 低 6 位 是否符合 110001
115739001 111001 ✗
214318436 100100 ✗
309480113 110001 ✓ → 明文 = 309480113 >> 6 = 4835626
408059548 011100 ✗

两条自检：$309480113^2 \bmod 523798549 = 162853095$（等于密文）✓；309480113 与密文 162853095 同为 9 位数字 ✓（"明文与密文长度相同"就是因为拼了校验码后位数不变）

脚本

  • Rabin密码-solve.py（本目录，含本题数据，纯 py 直跑）
  • ~/tools\CTF工具箱\crypto\20-Rabin密码.py（通用模板，改顶部 N / C / CHECK 三行；支持二进制校验码和十进制拼接两种 CHECK_DECIMAL 模式，自动分解 + 自动筛根 + 顺带出 md5）

易错点

  1. p == q 时 4 根退化——CRT 在模数不互素时会失败（base is not invertible）。标准 Rabin 要求 $p\ne q$ 的奇素数，脚本里已加保护。素数平方 $n=p^2$ 属于另一个题型，不能套这个模板。
  2. 校验码的进制别搞混：110001 是二进制（=49），不是十进制 110001。用 int(CHECK, 2)。
  3. 剥离方式取决于题目"怎么拼"：
    - 位拼接（m_拼接 = (m << k) | check）→ 明文 = root >> k
    - 十进制字符串拼接（明文4835626 + 49）→ 明文 = root // 10**len(check)，且此时要校验 root % 10**k == check
    两种含义下明文不同，本题是位拼接（明文 4835626）。脚本里 CHECK_DECIMAL 开关切换。
  4. 只有两个根也是正常的：$c$ 与 $p$ 或 $q$ 不互素、或 $c$ 是 0 时根会退化，别以为算错了。
  5. md5 要对"明文"做，不是对根做：本题两个哈希都不一样，提交要的是 md5("4835626")。
  6. $n$ 若大到纯 Python 分解吃力（> 60 位半素数），别硬跑——sympy.factorint / SageMath / yafu 接力。

面试速答卡

  • Q: Rabin 和 RSA 的关系？ A: Rabin 是 $e=2$ 的特例，加密为平方，解密为开平方；代价是四选一、必须带冗余。
  • Q: Rabin 为什么"可证明安全"？ A: 能解密（选出正确根）就意味着能分解 $n$：已知 $c$ 的两个不同根 $r_1, r_2$，则 $r_1 \not\equiv \pm r_2$，$\gcd(r_1-r_2, n)$ 直接给出 $p$ 或 $q$。
  • Q: 为什么要有校验码？ A: 4 个根无法区分，冗余信息用于唯一确定原文。
  • Q: 4 个根怎么来的？ A: 模 $p$、模 $q$ 各两根，CRT 独立组合 → $2\times2=4$。
