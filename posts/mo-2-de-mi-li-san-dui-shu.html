模2的幂-离散对数

密码学 2026-09-13 1438 字 约 4 分钟
crypto

题型识别（一眼看出）

  • 出题脚本形如：
n = 2 ** 256
c = pow(m, flaglong, n)   # m 是随机奇数，flaglong 就是 flag 的整数
  • 特征：模数是 2 的幂（2**k）、底数 m 是奇数、要还原指数 flag
  • 本质：(Z/2^k)^* 上的离散对数问题，但模 2 的幂群结构特殊，可秒解

核心原理：群分解

奇数乘法群可以拆成两半：
$$(\mathbb{Z}/2^k)^* \cong {\pm1} \times \langle 5 \rangle, \quad #\langle5\rangle = 2^{k-2}$$

即任意奇数都能唯一写成 m = ±5^b：
- 5^b ≡ 1 (mod 4) 恒成立 → 符号看 mod 4：m%4==1 取 +，m%4==3 取 -
- ⟨5⟩ 是阶为 2 的幂的循环群 → 指数部分可用 Pohlig–Hellman 按位求离散对数

解题步骤

  1. 剥符号：m' = m if m%4==1 else -m (mod 2^k)，同理 c' = c if c%4==1 else -c
    → 剥掉后 m' = 5^b、c' = 5^{b·e}，且都满足 ≡ 1 mod 4
  2. 求离散对数：B = dlog₅(m') = b，D = dlog₅(c') = b·e (mod 2^{k-2})
  3. 解出 e：令 t = v₂(B)（B 的 2 因子个数），则
    $$e = (D \gg t) \cdot (B \gg t)^{-1} \pmod{2^{k-2-t}}$$
    flag 一般只有 ~200 位，只要 t 不太大（本题 t=0）就能完整还原
  4. long_to_bytes(e) 得 flag

离散对数 dlog₅（Pohlig–Hellman 二进制版）

⟨5⟩ 的阶是 2^{k-2}，逐位求指数 d（d ∈ [0, 2^{k-2})）：

def dlog5(h, k=256):
    # 解 5^d = h (mod 2^k)，要求 h≡1 mod 4
    N = 1 << k; m_exp = k - 2
    g = 5; g_inv = pow(g, -1, N)
    d = 0; r = h % N
    for i in range(m_exp):
        val = pow(r, 1 << (m_exp - 1 - i), N)   # 剩最后"一半"指数，得到阶2元素的幂
        if val != 1:                              # 该位为 1
            d |= 1 << i
            r = (r * pow(g_inv, 1 << i, N)) % N  # 减掉已确定的低位
    return d

复杂度 O(k²) 次大数乘法，254 位模数秒出。

解题脚本

见同目录 模2的幂-离散对数-solve.py，换题只改 m/c 两个数据，py 直接跑。

易错点

  1. 不是普通 dlog：(Z/2^k)^* 不是循环群（有 3 个阶 2 的元素），不能直接拿 m 当生成元做 PH；必须先分解成 ±5^b
  2. 符号处理：m 或 c 是 3 mod 4 时取负值再算，否则 dlog5 会失败
  3. v₂(B) 影响精度：B 是偶数时只能解出 e mod 2^{k-2-t}；flag 很短（<2^200）时一般够用，若 t 太大可结合 flag 格式猜补

实战记录

  • 来源：DASCTF 题，k=256，m 为随机奇数，c = pow(m, flag, 2**256)
  • 本题 v₂(B)=0，直接 e = D * B^{-1} mod 2^254
  • flag：flag{DASCTF_zjut}
  • 难度评估：中等偏简单——认出群结构即秒解，属于"见过就会"类题型
