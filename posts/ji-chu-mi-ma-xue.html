ASCLL码

ASCII 是一种 7 位编码标准，允许使用整数 0-127 表示文本。
如以下列表
[99, 114, 121, 112, 116, 111, 123, 65, 83, 67, 73, 73, 95, 112, 114, 49, 110, 116, 52, 98, 108, 51, 125]
可以通过使用函数chr()与ord()可以实现单个字节与整数的转换，可以通过bytes()将整数序列转换成字节。

16进制

十六进制可以用来表示 ASCII 字符串。首先，每个字母根据 ASCII 表转换为序数。然后将十进制数转换为以 16 为基数的数字，也称为十六进制。这些数字可以组合在一起，形成一个长十六进制字符串。
63727970746f7b596f755f77696c6c5f62655f776f726b696e675f776974685f6865785f737472696e67735f615f6c6f747d
可以通过函数bytes.fromhex()与.hex()实现16进制字符串与字节序列的转换
python中的进制转换,表示将字符串m从n进制转换成10进制

print(int(m,n))

Base64

Base64，它允许我们使用 64 个字符的字母表将二进制数据表示为 ASCII 字符串。Base64 字符串的一个字符编码 6 个二进制数字（位）
此 Base64 的 4 个字符编码三个 8 位字节。
Base64 最常在线使用，因此可以轻松地将图像等二进制数据包含在 HTML 或 CSS 文件中。
在 Python 中，import base64 后：base64.b64encode(data) 是编码（bytes → base64 字节串），base64.b64decode(s) 才是解码（base64 → 原始 bytes）。做题常见流程：bytes.fromhex(hex密文) → b64encode → 得到 crypto{...}

字节和大整数

像 RSA 这样的密码系统处理数字，但消息由字符组成。我们应该如何将我们的信息转换为数字以便可以应用数学运算？
最常见的方法是获取消息的序号字节，将它们转换为十六进制，然后连接起来。这可以解释为以 16 为基数/十六进制数，也可以以 10 为基数/十进制表示。例如
消息：HELLO
ASCII 字节：[72、69、76、76、79]
十六进制字节：[0x48、0x45、0x4c、0x4c、0x4f]
base-16：0x48454c4c4f
base-10：310400273487
函数bytes_to_long() long_to_bytes() from Crypto.Util.number import *可以实现字节序列与长整数的转换

哈希

哈希是将信息转换为固定长度密文的算法

hashlib.md5()        # MD5，128位，已不安全，仅用于校验
hashlib.sha1()       # SHA-1，160位，已不推荐
hashlib.sha256()     # SHA-256，256位，目前最常用 ✅
hashlib.sha512()     # SHA-512，512位，更安全但更慢
hashlib.sha3_256()   # SHA-3 系列，新一代标准

异或

XOR 是一个按位运算符，如果位相同，则返回 0，否则返回 1。在教科书中，异或运算符用⊕表示，但在大多数挑战和编程语言中，您会看到使用插入符号。 ^
对于较长的二进制数，我们逐位异或： 我们可以通过首先将整数从十进制转换为二进制来对整数进行异或或。我们可以通过首先将每个字符转换为表示 Unicode 字符的整数来对字符串进行异或。
Python 库有一个方便的函数，可以将不同类型和长度的数据进行异或。但首先，您可能想要实现自己的函数来解决这个问题。pwntools xor()

xor的用法

from pwn import xor 后调用 xor(data, key)：

  • data：输入数据（bytes 或 int）
  • key：密钥（bytes、int 或列表/元组）
  • 返回：异或结果，类型与 data 一致

⚠️ 统一成 bytes 最省心：题干给 hex 串就先 bytes.fromhex()，给可见字符串就先 .encode()，别把 str 和 bytes 混着传。本题的 c = 'crypto{' 是 str，靠 pwnlib 隐式编码才跑通——只是能跑，不代表是好习惯。

异或的属性

交换：A ⊕ B = B ⊕ A
联想：A ⊕ （B ⊕ C） = （A ⊕ B） ⊕ C
恒等式：A ⊕ 0 = A
自逆：A ⊕ A = 0
我们可以通过这些属性化简题目
推论：如果A ⊕ B = C 那么A ⊕ C = B
通过推论我们可以知道如果知道：如果知道密文和明文头，可以得出部分密钥。例如：

from pwn import *
n='0e0b213f26041e480b26217f27342e175d0e070a3c5b103e2526217f27342e175d0e077e263451150104'
m=bytes.fromhex(n)
c='crypto{'
b=xor(m,c)
print(b)

对图片的异或

基本原理：图片由许多像素点排列组成，我们可以把每个像素点的灰度或RGB(red,green,blue,可以认为每个像素点的颜色是由这三种颜色不同比例混合而成的)的数值当作异或的对象。将异或得到的数值再转化为灰度或RGB，形成新的图片。
常用的工具：python的PIL库

from PIL import Image
image1 = Image.open(r"~/ 图片\flag_7ae18c704272532658c10b5faad06d74.png")
image2 = Image.open(r"~/ 图片\lemur_ed66878c338e662d3473f0d98eedbd0d.png")
#生成可操作的对象，pim类似于矩阵，通过坐标值来操控每个像素
pim1 = image1.load()
pim2 = image2.load()
width,height=image1.size
for i in range(width):
    for j in range(height):
        r1,g1,b1 = pim1[i,j]
        r2,g2,b2 = pim2[i,j]
        pim1[i,j] = (r1^r2, g1^g2, b1^b2)
image1.show()
