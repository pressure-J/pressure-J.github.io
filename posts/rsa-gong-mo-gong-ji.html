RSA共模攻击

密码学 2026-09-02 2278 字 约 6 分钟
crypto

题型识别（一眼看出）

题目给两对加密结果，特征三选一即可怀疑共模攻击：

  • 同一明文 m、同一模数 n，两个不同指数 e1/e2 分别加密出 c1/c2
  • 给了 c1, c2, e1, e2, n 五个数，且 e1 ≠ e2
  • 出题脚本形如：
n = p*q
c1 = pow(m, e1, n)
c2 = pow(m, e2, n)

本质：RSA 模数重用（同一个 n 加两次密）是致命错误 → 不用分解 n、不用知道 p/q，纯数学还原明文。

攻击条件

  • gcd(e1, e2) = 1（两指数互素）
  • 扩展欧几里得求出的 s1、s2 满足 e1*s1 + e2*s2 = 1

原理推导

由加密关系：
$$c_1 = m^{e_1} \bmod n, \quad c_2 = m^{e_2} \bmod n$$

对两个密文做"指数线性组合"：
$$c_1^{s_1} \cdot c_2^{s_2} = m^{e_1 s_1} \cdot m^{e_2 s_2} = m^{e_1 s_1 + e_2 s_2} = m^1 = m \pmod n$$

核心：用扩展欧几里得（贝祖定理）把两个指数凑成线性组合 = 1，明文自己跳出来。

def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = egcd(b, a % b)
    return g, y1, x1 - (a // b) * y1

g, s1, s2 = egcd(e1, e2)
print(f"gcd = {g}")
assert g == 1, "gcd != 1，需要变式处理"

def pow_signed(c, s, n):
    if s < 0:
        return pow(pow(c, -1, n), -s, n)   # c^(-k) = (c^(-1))^k
    return pow(c, s, n)

m = pow_signed(c1, s1, n) * pow_signed(c2, s2, n) % n
flag = m.to_bytes((m.bit_length() + 7) // 8, 'big').decode()
print(f"FLAG: {flag}")
# 本题结果: NSSCTF{xxxxx******xxxxx}

易错点

  1. 负指数：s 可能为负，pow(c, -k, n) 报错要先取模逆再乘方
  2. gcd > 1 的变式：若 gcd(e1,e2) = g，则只能凑出 e1*s1 + e2*s2 = g，解得的是 m^g。若 g 较小（且和 n 互素），可对结果开 g 次方（整数开根/iroot）；g 太大则此路不通
  3. 平台 flag 可能是"掩码样"的真是答案：NSSCTF 部分题 flag 本身就是 NSSCTF{xxxxx******xxx} 这类带星号格式，解出来长这样≠解错（出题人故意设计的 flag 格式）
