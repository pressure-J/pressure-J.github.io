Misc视频隐写解题步骤

Misc 2026-10-10 4293 字 约 11 分钟
miscvideostego

配套脚本：工具箱 misc\13-视频抽帧与隐写排查.py（info/frame/secs/all/spike/crop/audio 七个子命令）
依赖：ffmpeg + ffprobe（本机在 Hermes tools 目录，脚本会自动找）；spike 子命令需 Pillow + numpy（本机已装）

一、三条铁律(先读)

  1. 先算帧号,别瞎找:题面给的时间点经常是干扰项。真实位置要靠算法找,不能靠题面。
  2. 不用下载视频软件:ffmpeg 一条命令全提帧,不需要播放器逐帧点。
  3. 先看"有没有",再纠结"是什么":先定位到可疑区域,再放大识别字符。

二、第一步永远是 info(读帧率)

帧号 = 秒 × 帧率。帧率不能假设,必须读:

py 13-视频抽帧与隐写排查.py info 视频.mp4

输出示例(本题):

流类型: video, audio
视频: h264 480x864  30/1 fps  399 帧
时长: 13.30 秒
字幕轨: 无（提示是烧进画面的，需抽帧看）

帧率 = 30 fps
★ 帧号换算: 帧号 = 秒 × 30
  例: 5.66 秒 -> 第 169.8 帧

读帧率同时要看有没有字幕轨:
- 有字幕轨 → 直接 ffmpeg -i v.mp4 -map 0:s:0 subs.srt 导出,不用抽帧
- 无字幕轨 → 提示是烧进画面的,必须抽帧

帧率换算表(常用)

帧率 5.66s 7.36s 备注
24 fps f_136 f_177 电影
25 fps f_142 f_185 PAL
30 fps f_170 f_221 网络视频最常见
60 fps f_340 f_442 高帧率

三、抽帧的三种颗粒度

py 13-视频抽帧与隐写排查.py all   视频.mp4          # 全提帧到 frames/(推荐)
py 13-视频抽帧与隐写排查.py frame 视频.mp4 5.66     # 只取第 5.66 秒
py 13-视频抽帧与隐写排查.py secs  视频.mp4 5.66 7.36 # 批量取多个时间点

全提帧优先。原因:题面给的时间点可能是错的,只有全帧在手才能用"孤帧检测"自己找。
399 帧的短视频抽完只要 1 秒左右。

四、⭐ 孤帧检测(核心技巧,值得单独记)

原理:水印/文字通常只闪一两帧。正常连续帧之间变化平缓,而"被叠加了一层的帧"会和前后帧差异巨大。

第 i 帧的孤帧强度 = |帧i - median(帧i-3, 帧i-2, 帧i-1, 帧i+1, 帧i+2, 帧i+3)|

用前后各 3 帧的中位数当参考(排除自己),比"和前一帧比"稳得多——人物运动也会造成帧间差异,取中位数能滤掉。

py 13-视频抽帧与隐写排查.py spike 视频.mp4

输出按强度排序的候选帧列表,并自动导出 Top12 的顶部/底部放大图:

=== "瞬时叠加"嫌疑最大的 15 帧 ===
  帧号      强度    时间(30fps 仅供参考)
  f_0009     165.0   0.30s
  f_0138     161.0   4.60s
  ...
  f_0171     157.0   5.70s      ← 真水印帧,排第 9
  f_0170     156.0   5.67s      ← 真水印帧,排第 11

导出 Top12 的顶部与底部放大图(4x)...
  f_0171 (强度157) -> spike_f0171_top.png / _bot.png

⚠️ 孤帧检测的关键认知

排名靠前 ≠ 就是水印帧。人物大幅运动同样产生高 spike。本题真水印帧 f_0170/0171 只排第 9/11 名,如果只看 Top3 就会错过。

所以:要看 Top10~15,不能只看前几名。 脚本默认导出 12 个就是为了这个。

五、水印/文字的定位与放大

半透明水印通常出现在画面顶部或底部(避开主体),而且又小又淡,直接看是糊的,必须裁切放大。

5.1 先定位在哪一行

# 逐行统计亮像素,亮像素突然集中的行 = 水印所在行
for y in range(H):
    n = (a[y] > 205).sum()
    if n > 3:
        print('y=%d 亮像素=%d' % (y, n))

本题实测:水印在 y≈136~146(顶部区域)。

5.2 裁切 + 放大(工具命令)

py 13-视频抽帧与隐写排查.py crop frames/f_0171.png 128 152 12
#                                          ↑图 ↑起 ↑止 ↑放大倍数

得到 crop_f_0171_128_152.png,5760x288(12 倍)。

5.3 放大倍数怎么选

水印大小 建议倍数 说明
大(占屏宽 1/3+) 4x 够了
中 8x
小(一条细线) 12x+ 本题用 12x 才看清

放大后如果还是糊:先试缩小裁切范围(只切水印那一行 ±10px),再放大。切得越精准,有效放大倍数越高。

六、识别到字符后:先做格式猜测

特征 编码 解法
结尾 = / ==,含 A-Za-z0-9+/ base64 base64.b64decode()
只含 0-9a-f,长度偶数 hex bytes.fromhex()
只含 0/1 二进制 int(x, 2) → bytes
%XX 形式 URL urllib.parse.unquote()
点划线 摩斯 查表

本题:dXBfdXBfdXA= → base64 → up_up_up

⚠️ 关键认知:水印是分段的

本题两帧各藏一段,必须拼起来才是完整密码:

时间 帧 水印 解码
5.66s f_0170/0171 (另一段) wllm
7.36s f_0221/0222 dXBfdXBfdXA= up_up_up

拼起来 = wllmup_up_up → 这正是 flag2.zip 的密码。

别看到一段就收工,题目常把一个串拆成好几个帧。

七、音频方向(别忘了)

视频题不一定只看画面:

py 13-视频抽帧与隐写排查.py audio 视频.mp4     # 抽成 wav

抽出来后用 Audacity 打开 → 切频谱图(spectrogram):

现象 含义
频谱里出现文字/图案 音频水印(频谱隐写)
高低音频交替、有节奏 摩斯电码
双音组合 DTMF 电话拨号音

八、常见坑

坑 现象 处理
信了题面给的时间 怎么找都没有 题面可能是干扰,用 spike 自己找(本题就是)
假设 30fps 帧号对不上 先 info 读真实帧率
只导出 Top3 候选 漏掉真水印帧 看 Top10~15,真帧可能在 9~11 名
直接看原帧找水印 糊成一团看不清 必须裁切 + 放大 8~12 倍
裁切范围太大 放大后仍看不清 缩小到水印那一行 ±10px 再放大
看到一段就收工 密码不完整 水印常分段,要把多帧拼起来
只查画面不看音频 漏掉音频隐写 顺手抽音频看频谱
-vsync 报错 新版 ffmpeg 不认 用 -fps_mode passthrough

九、实战记录:你有没有好好看网课(SWPU2019)

三层结构,flag3 内视频是第二层的密码来源。

步骤 操作 结果
① 看注释 zipinfo -z flag3.zip "依稀记得是6位数字" → 爆破真加密 zip
② 爆破 ZipCrypto 两级验证 口令 183792,解出 flag.docx + mp4
③ 读 docx 逐 <w:t> 还原 "从小5就2 0列文虎克,我每年的7月1 1日的生日愿望就是拥有一个🔍"
④ docx 配图 导出 word/media/image1.jpeg 列文虎克(显微镜之父)肖像 → "仔细观察"
⑤ 算帧号 info 30fps,题面数字 5.20/7.11 → ❌ 找不到
⑥ 孤帧检测 spike f_0171(5.66s) 排第 9 → 有戏
⑦ 裁切放大 crop y=128~152 放大 12x 看到 dXBfdXBfdXA=
⑧ base64 解码 up_up_up(7.36s 那帧的另一段拼上 → wllmup_up_up)
⑨ 解 flag2 7z x flag2.zip -pwllmup_up_up Real flag.jpg 尾部 → swpuctf{A2e_Y0u_Ok?}

这题的三个教训

  1. docx 里的 5 2 0 7 1 1 是干扰——真实位置是 5.66s / 7.36s。按题面数字找永远找不到。
  2. 真水印帧在孤帧排名第 9/11,只导出 Top3 就漏了。这是差点失败的节点。
  3. 水印分两段,两个时间点各一段,拼起来才是密码。

十、工具箱命令速查

# 1. 读参数(帧率/时长/帧数/字幕轨) —— 永远先做
py 13-视频抽帧与隐写排查.py info   视频.mp4

# 2. 全提帧(推荐)
py 13-视频抽帧与隐写排查.py all    视频.mp4

# 3. 孤帧检测(自动找闪烁水印)⭐
py 13-视频抽帧与隐写排查.py spike  视频.mp4

# 4. 裁切+放大(看清水印)
py 13-视频抽帧与隐写排查.py crop  frames/f_0171.png 128 152 12

# 5. 抽音频看频谱
py 13-视频抽帧与隐写排查.py audio  视频.mp4

纯命令等价写法(没有脚本时)

ffprobe -v error -select_streams v:0 -show_entries stream=r_frame_rate,nb_frames -of default=nw=1 视频.mp4
ffmpeg -i 视频.mp4 -fps_mode passthrough frames/f_%04d.png     # 全提帧
ffmpeg -ss 5.66 -i 视频.mp4 -frames:v 1 frame.png              # 取某一秒
ffmpeg -i 视频.mp4 -vn -acodec pcm_s16le out.wav               # 抽音频
