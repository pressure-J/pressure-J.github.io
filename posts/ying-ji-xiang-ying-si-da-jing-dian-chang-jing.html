应急响应四大经典场景

应急响应 2026-07-10 2373 字 约 6 分钟
应急响应CTF总结

一、四大经典出题场景

1. Web日志分析（出现频率最高）

给 Apache/Nginx/IIS 访问日志或 error log，考点通常是：

统计爆破/扫描源IP：SSH爆破(/var/log/secure)、Web目录扫描、SQL注入试探

定位Webshell上传/访问：过滤 POST 请求、200状态码、可疑UA（蚁剑/哥斯拉特征）、jsp/php/asp 后缀文件访问

提取攻击者IP、时间、利用的漏洞路径（如 /manager/html、/upload.php）

问 Top N 访问IP、最早攻击时间、被上传的Webshell文件名

套路：用 grep/awk/sort/uniq -c统计，或用 Python 脚本正则匹配

2. Webshell与Web目录排查

给一个被入侵网站的 Web 根目录打包，要求：

找出隐藏/混淆的 Webshell（文件名含点如 .shell.php、藏在 images/``include/等目录、base64/rot13/gzip 混淆）

问 Webshell连接密码/工具类型（菜刀 z0/z1、冰蝎 AES、哥斯拉 MD5特征）

找出不死马（不死PHP马、写 .user.ini自动包含）及其生成文件

Flag 通常在 Webshell 源码注释、eval(base64_decode(...))解码后、或文件里藏的 flag{}

套路：find按 mtime 找新增文件 → grep -R "eval\|base64\|assert\|preg_replace"→ 人工或工具(D盾/河马)扫 → 解码

3. 流量包分析（Wireshark + 解密）

给 .pcapng，常见套路：

HTTP 流量中还原 Webshell 交互：跟踪 TCP 流，找 POST body 中的 Base64/AES 密文，冰蝎/哥斯拉需提取密钥解密

FTP/SMB/HTTP 文件还原：导出对象(Export Objects)，还原攻击者上传的木马或下载的敏感文件

DNS 隧道/CTF 隐蔽通道：过滤 dns看 TXT 记录或长子域名，提取编码数据

问攻击者IP、C2域名、上传文件名、解密后命令

套路：Wireshark → Statistics → Conversations/HTTP → Follow TCP Stream → 导出/解码

4. 系统取证（Linux/Windows 内存 & 磁盘镜像）

Linux 排查：/etc/passwd查后门账号、authorized_keys查SSH公钥后门、crontab/systemd查持久化、.bash_history查操作痕迹、/tmp下可疑 ELF

Windows 排查：隐藏账号/克隆账号(lusrmgr.msc/注册表)、计划任务、启动项、Prefetch/Amcache 找恶意程序执行记录

内存取证(Volatility)：pslist找异常进程、netscan找外连、cmdscan/consoles看命令行、filescan/dumpfiles提取文件、hashdump抓 SAM

磁盘镜像(Autopsy/foremost)：恢复被删除的文件、找隐藏分区中的 flag

Flag 常在进程内存字符串、被删文件内容、dump出的配置文件里

二、高频问答形式（答题模板）

问法 典型答法
攻击者IP 日志/流量中最早出现扫描或成功登录的IP
Webshell路径 Web目录下找到的含eval/base64的php/jsp完整路径
Webshell密码/工具 解码后看到 $_POST['xxx']的 key，或工具特征(Godzilla/Behinder/AntSword)
最早入侵时间 日志中首个攻击请求或 .php文件 mtime
后门账号名 /etc/passwd新增 UID≥1000 或 /etc/shadow无密码账户
恶意文件MD5 对找到的木马文件 md5sum
反弹Shell目的端口/C2域名 流量中外连TCP连接的目的IP:Port 或 DNS查询域名

三、通用解题套路（SOP）

1. 先看题目描述 → 明确给了什么(日志/流量/镜像/目录)
2. 按时间线梳理：
   - 日志：爆破→成功登录/漏洞利用→Webshell上传→命令执行
   - 流量：扫描→交互→文件传输
3. 用特征过滤(关键字: eval/base64/cmd/whoami/z0/Go/Behinder)
4. 提取异常文件→解码/反混淆→找flag{}
5. 溯源填空(IP/时间/路径/密码/工具名)

四、常考知识点速记

日志路径：Ubuntu /var/log/auth.log，CentOS /var/log/secure，Nginx /var/log/nginx/access.log

Webshell特征：eval(base64_decode())、assert、create_function、$_POST['x']、@ini_set

内存取证命令：imageinfo → pslist → netscan → cmdscan → linux_find_file → dumpfiles

隐藏手段：.开头隐藏文件、改名 .jpg.php、写进图片 EXIF、不死马死循环重写自身
