概述

Windows 系统日志是应急响应中最常用的数据源之一。掌握日志存放位置、关键事件 ID 和分析方法，是解题和实战的基本功。

一、日志存放位置

日志类型 默认路径 说明
安全日志 C:\Windows\System32\winevt\Logs\Security.evtx 登录、权限变更、策略修改
系统日志 C:\Windows\System32\winevt\Logs\System.evtx 系统服务、驱动、开机事件
应用日志 C:\Windows\System32\winevt\Logs\Application.evtx 应用程序错误、崩溃信息
PowerShell ...\Microsoft-Windows-PowerShell%4Operational.evtx PowerShell 命令执行记录
RDP ...\Microsoft-Windows-TerminalServices-* 远程桌面连接记录
计划任务 ...\Microsoft-Windows-TaskScheduler%4Operational.evtx 计划任务创建/执行

提示：.evtx 是二进制格式，需要用工具解析（Event Log Explorer、LogParser、python-evtx）。

二、安全日志关键事件 ID

登录相关

EventID 含义 应急关注点
4624 登录成功 关注 LogonType=10（RDP）
4625 登录失败 大量失败 = 暴力破解，统计源 IP
4634 登出 辅助确认会话时长
4648 显式凭据登录 可能涉及横向移动
4672 特殊权限分配 管理员登录时触发

账户与策略

EventID 含义 应急关注点
4720 用户账户创建 攻击者创建后门账户
4722/4725 账户启用/禁用 禁用管理员可能是攻击
4732 成员添加到本地组 加入 Admins 组 = 提权
4776 NTLM 认证 暴力破解时大量失败
4778/4779 RDP 会话重连/断开 追踪远程桌面使用

三、LogonType 速查表

LogonType 名称 说明 应急场景
2 Interactive 本地控制台 物理接触
3 Network 网络访问（IPC$） 横向移动
4 Batch 计划任务 持久化
5 Service 服务启动 后门服务
10 RemoteInteractive RDP 远程桌面 暴力破解重点
11 CachedInteractive 缓存凭据登录 离线认证

五、CTF 常见考点

考点 解题思路
暴力破解源 IP 筛选 4625，按 IP 分组统计
成功登录账户 筛选 4624 + LogonType，提取 TargetUserName
后门账户创建 搜索 4720 + 4732
RDP 远程登录 LogonType=10 的 4624 记录
计划任务持久化 搜索 4698
