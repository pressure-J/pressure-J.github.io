RSA-构造A反推参数

密码学 2026-09-08 1437 字 约 4 分钟
crypto

题型识别（一眼看出）

题目给一个大整数公式 A（含 x/y/z 的幂运算）+ n + c，形如：

A = (((y%x)**5)%(x%y))**2019 + y**316 + (y+1)/x
p = next_prime(z*x*y)
q = next_prime(z)
n = p*q
c = pow(m, e, n)

本质：A 是"提示"，用来反推 x、y；再用 x、y 与 n 的关系定位 z，从而分解 n。所有计算都是构造上留的门，不需要硬分解大数。

攻击条件

  • A 中有一项是某个变量的高次幂主导项（如 y**316）
  • 另一项是超大指数幂（如 **2019），底数必然很小才不爆炸
  • p、q 由 z 派生，比值 p/q ≈ x*y 近似为常数

原理推导与步骤

① 整数开根分离 y
A 是 607 位大数，y**316 是主导项，**2019 那项若底数≥2 会直接超过 A（2^2019 就够大），所以底数 ∈ {0,1}。
$$y = \lfloor A^{1/316} \rfloor$$

② 余数反推 x
$$A - y^{316} = \underbrace{(((y\%x)^5)\%(x\%y))^{2019}}_{\in{0,1}} + \frac{y+1}{x}$$
对小的 x 逐个试，找出使等式成立的 x（本题 x=2）。

③ 用 x·y 估计 z 分解 n
由 p ≈ z·x·y、q ≈ z：
$$n = p\cdot q \approx (x\cdot y)\cdot z^2 \;\Rightarrow\; z \approx \sqrt{n/(x\cdot y)}$$
在 isqrt(n//(x*y)) 附近搜索 n 的因子即得 q，再 p = n//q。

④ 常规 RSA
d = e⁻¹ mod (p-1)(q-1)，m = c^d mod n，转 bytes 得 flag。

解题脚本

见 ~/tools\CTF工具箱\crypto\ 下同主题脚本（本题数据改顶部数据行即跑）

y = iroot(A, 316)                     # ① 整数开根
rem = A - y**316                      # ② 余数
x = 反推(rem)                          #    试小 x
z_est = isqrt(N // (x*y))             # ③ 估计 z
q = 在 z_est 附近搜 N 的因子
p = N // q
d = pow(E, -1, (p-1)*(q-1))           # ④ 解密
m = pow(C, d, N)

易错点

  1. 别被超大指数吓住：**2019 是障眼法，底数只能 0/1，关键是敢试小值
  2. 整数开根别用浮点：几百位大数用 x**(1/k) 会溢出，用整数牛顿/二分 iroot
  3. 没给 e：默认 65537，也可列表逐个试
  4. 定位因子要留窗口：z_est 有误差，搜索范围放宽到 ±几十万，直接试 N % cand == 0
  5. p/q 可作校验：算出的 p/q 应 ≈ x*y，对不上说明 x/y 反推错了
  6. (y+1)/x 的除法：题目里通常是整数除；若余数对不上，考虑真实除法

实战记录

  • 来源：RoarCTF 构造题
  • A 607 位 → y = iroot(A,316) = 83，余数 43 → 试出 x=2（1^2019 + 84/2 = 1+42 = 43）
  • z ≈ sqrt(n/166) 附近搜到 q（差 546），p/q = 166.0000 = x*y ✓
  • e=65537，结果：RoarCTF{wm-l1l1ll1l1l1l111ll}
