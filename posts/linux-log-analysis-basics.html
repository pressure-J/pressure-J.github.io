应急响应日志分析Linux

Linux常见目录

/var/log/syslog：记录系统的各种信息和错误。
/var/log/auth.log：记录身份验证相关的信息，如登录和认证失败。
/var/log/kern.log：记录内核生成的日志信息。
/var/log/dmesg：记录系统启动时内核产生的消息。
/var/log/boot.log：记录系统启动过程中的消息。
/var/log/messages：记录系统的广泛消息，包括启动和应用程序信息。
/var/log/secure：记录安全相关的消息。
/var/log/httpd/：记录Apache HTTP服务器的访问和错误日志（若安装了Apache）。
/var/log/nginx/：记录Nginx服务器的访问和错误日志（若安装了Nginx）。

一、全局通用（所有发行版几乎一致）

目录 应急关注点 常见用途
/etc ⭐⭐⭐⭐⭐ 账号、cron、服务配置
/var/log ⭐⭐⭐⭐⭐ 登录、系统、应用日志
/tmp ⭐⭐⭐⭐ Webshell、挖矿、恶意脚本
/dev/shm ⭐⭐⭐⭐ 内存型落盘，重启消失
/proc ⭐⭐⭐⭐⭐ 实时进程反查
/root ⭐⭐⭐ root 历史命令、私钥
/home ⭐⭐⭐ 用户级后门
/usr/bin ⭐⭐⭐ 被替换的命令（ls/ps/top）
/boot ⭐⭐ rootkit / 启动项

二、日志文件速查（重点）

日志 作用
secure / auth.log SSH、sudo、登录
messages 系统级事件
cron 定时任务（持久化）
dmesg 内核日志
journalctl systemd 统一日志
nginx/access.log Web 攻击、Webshell
nginx/error.log 报错、路径泄露
apache/access.log Web 攻击
mysql.log SQL 注入、暴力破解

三、日志查询命令

核心思想：cat 日志 | grep 关键字 | 处理命令

grep的使用

grep "Failed password" /var/log/secure     # 包含关键字
grep -i "accepted" /var/log/secure         # 忽略大小写
grep -v "normal" file                      # 排除某关键字
grep -E "Failed|Invalid" file              # 扩展正则（或）
grep "from 192.168.1.1" file               # 指定 IP
grep -c "Failed" file                      # 只显示匹配行数

常用管道搭配参数

命令 作用 示例
wc -l 统计行数（次数） `
sort 排序 `
uniq 去重（需先 sort） `
uniq -c 去重并计数 ⭐ `
awk '{print $N}' 取第 N 列 ⭐ `
head -$n 看前n行 ··、

常用命令

查ip

awk '{print $1}' access.log | sort | uniq -c | sort -rn | head

查某小时访问最多ip

grep "06/Jul/2026:10:" access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head

提出黑客ip的user-agent

grep "192.168.200.2" access.log.1 | awk -F'"' '{print $6}' | sort | uniq -c | sort -rn
