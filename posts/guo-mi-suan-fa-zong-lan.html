国密算法总览

密码学 2026-10-14 3011 字 约 8 分钟
cryptosm2sm3sm4

国产商用密码算法族。算法原理与攻击面已拆成三篇独立笔记，本篇只留体系总表、选型导航与公共工具链。

1. 三篇导航

算法 笔记 一句话定位
SM2 SM2-椭圆曲线公钥算法原理与攻击 256 位 ECC 公钥算法（签名/密钥交换/加密），对标 ECDSA
SM3 SM3-杂凑算法原理与攻击 256 位杂凑，MD 结构，对标 SHA-256
SM4 SM4-分组密码原理与攻击 128 位分组对称，32 轮非平衡 Feistel，对标 AES

2. 算法体系总表

算法 类型 参数 对标 标准号
SM1 分组对称 128/128 — 硬件实现，算法不公开
SM2 椭圆曲线公钥 256 位素域 ECDSA / RSA GM/T 0003
SM3 杂凑 输出 256 位 SHA-256 GM/T 0004
SM4 分组对称 128/128 AES GM/T 0002
SM9 标识密码 IBC — 替代 PKI（无需证书） GM/T 0044
ZUC 祖冲之 序列密码 128 位密钥 — 4G/5G 空口加密
SM7 分组对称 — — 非接触 IC 卡

国际标准化：SM2 进 ISO/IEC 14888-3、SM3 进 ISO/IEC 10118-3、SM4 进 ISO/IEC 18033-3。

安全强度：SM2 的 256 位曲线离散对数需 $\approx 2^{128}$，等价 AES-128。

曲线 a/b/G 非标准 / 服务端不校验点 无效曲线、小阶子群 SM2 §3.3 —

4. 公共工具链（本机已实测）

工具 状态 说明
OpenSSL 3.5.5 ✅ 原生支持 SM2/SM3/SM4 全支持，不需要装 GmSSL CLI
Python gmssl ✅ 已装 sm2 / sm3 / sm4 三个模块
Python hashlib ❌ 标准库不提供 SM3，别在这找
PyCryptodome ❌ 不支持国密，别在这找 
# SM3
echo -n abc | openssl dgst -sm3

# SM4（注意 -nopad，否则会多输出一个填充块）
openssl enc -sm4-ecb -nopad -K 0123456789abcdeffedcba9876543210 -in block.bin | xxd -p

# SM4-CBC 往返
KEY=0123456789abcdeffedcba9876543210
IV=000102030405060708090a0b0c0d0e0f
openssl enc -sm4-cbc -K $KEY -iv $IV -in p.txt -out c.bin
openssl enc -d -sm4-cbc -K $KEY -iv $IV -in c.bin

# SM2 密钥对
openssl genpkey -algorithm ec -pkeyopt ec_paramgen_curve:SM2 -out sm2.key
openssl pkey -in sm2.key -pubout -out sm2.pub

# SM2 签名 / 验签
openssl pkeyutl -sign   -in p.txt -inkey sm2.key -rawin -digest sm3 -out sig.bin
openssl pkeyutl -verify -in p.txt -sigfile sig.bin -inkey sm2.pub -pubin -rawin -digest sm3

# SM2 加密 / 解密
openssl pkeyutl -encrypt -in p.txt -inkey sm2.pub -pubin -out enc.bin
openssl pkeyutl -decrypt -in enc.bin -inkey sm2.key

5. 公共踩坑速查

坑 在哪篇详述
验签缺 -pubin → Could not find private key SM2 §4.2
gmssl 的 sign(msg, K) 必须传 K；sign 不做 ZA（要用 sign_with_sm3） SM2 §4.2
OpenSSL 的 SM2 密文是 DER（含 INTEGER/OCTET STRING 结构），不是裸 C1C3C2 SM2 §4.1
SM2 不能照抄 ECDSA 的 k 重用公式 SM2 §3.1
SM3 长度扩展：填充分两处（glue 归属），长度必须爆破 SM3 §3.1
gmssl.sm3_hash 接收 list 不是 bytes SM3 §4
openssl enc -sm4-* 默认 PKCS 填充，取标准向量要加 -nopad SM4 §2.4
gmssl 的 CryptSM4 没有 OFB/CTR，要用 one_round 自己拼 SM4 §4
