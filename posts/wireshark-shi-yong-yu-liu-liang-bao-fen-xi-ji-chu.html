Wireshark使用与流量包分析基础

基础 2026-09-09 1987 字 约 5 分钟
network

一、Wireshark 是什么

Wireshark 是一个抓取/查看网络数据包的工具。数据在网络中按**数据包(packet)**传输,像一封封信。Wireshark 能把这些包拆开,把三层内容全展示出来。

二、网络分层心智模型

数据发送时套三层"包装"(像快递):

层 快递类比 协议 内容
应用层 信的内容 HTTP/FTP/DNS 真正的数据(网页、flag)
传输层 贴的标签 TCP/UDP 端口号、顺序号
网络层 快递单 IP 源IP、目标IP

Wireshark 就是帮你把每个包的三层包装逐层拆开看。

三、界面三大面板

双击一个包后,窗口分三栏:

┌─────────────────────────────────────────────────┐
│ ① 包列表(上)  所有包的"目录",一行一个包       │
├─────────────────────────────────────────────────┤
│ ② 包详情(中)  选中包的"分层拆解"             │
│    Frame → Ethernet → IP → TCP → HTTP         │
├─────────────────────────────────────────────────┤
│ ③ 包字节(下)  原始二进制,左hex右ASCII        │
└─────────────────────────────────────────────────┘

记忆:①看整体 → ②看分层 → ③看原始字节。

四、核心操作

1. 打开文件

File → Open,支持 .pcap / .pcapng 格式。

2. 显示过滤器(最重要)

顶部绿色输入框,只显示符合条件的包。做题第一步永远是这个。

http              → 只看HTTP
tcp                → 只看TCP
dns                → 只看DNS
ip.src == 1.2.3.4  → 只看这个IP发出的
tcp.port == 80     → 只看80端口

3. Follow TCP Stream(追完整对话)

对 TCP 包 右键 → Follow → TCP Stream,显示完整请求+响应内容(把拆散的包拼回原始对话)。

原理:数据被拆成很多小包(像书撕成一页页寄出),单独看任何一包都是碎片。Follow 做的事:
1. 按 源IP:端口+目标IP:端口 找出同一条流的全部包
2. 剥掉每层包装
3. 按顺序拼回原样

一句话:普通视图=看一堆信封;Follow 流=把某一封信的所有信封拆开拼回完整内容。

4. Export Objects(导出流量里的文件)

File → Export Objects → HTTP,列出所有通过 HTTP 传输的文件,一键导出。图片、压缩包、flag 文件都在这。

5. 搜索

Ctrl+F → 选 String / Packet bytes → 搜 flag / { / key。

五、流量包基本信息

常见格式

  • .pcap:经典格式(旧)
  • .pcapng:新格式,可存多条接口流量

常用工具(命令行)

Wireshark 自带 tshark.exe,可直接命令行分析:

tshark -r 文件.pcap -q -z io,phs        # 协议统计,看哪个协议占大头
tshark -r 文件.pcap -q -z conv,tcp      # TCP 会话列表(有多少条流)
tshark -r 文件.pcap -q -z follow,tcp,ascii,0   # Follow 第0条流,ASCII显示
tshark -r 文件.pcap -Y "http.request" -T fields -e http.request.uri  # 过滤+提取字段

常见端口

端口 服务
80 / 443 HTTP / HTTPS
22 SSH
21 / 20 FTP
25 / 110 SMTP / POP3
53 DNS
3306 MySQL
7890 / 1080 常见代理端口

六、常见坑

  1. 包 ≠ 流:包列表一行一个包;一条流可能被拆成几十上百个包。看到一堆小包先 Follow,别一个个看。
  2. 一个字符一个包:有些题每个包只带 1 字节(如代理流量),Follow 后拼回完整文本。
  3. 扩展名可伪造:导出的文件先用工具识别真实类型,别信后缀。
  4. 搜索字符串:看到乱码先 Ctrl+F 搜 flag / {,比肉眼扫快得多。

七、本机环境

  • Wireshark 便携版:~/tools\Wireshark\Wireshark.exe
  • tshark 命令行:~/tools\Wireshark\tshark.exe
  • Wireshark 未加入系统 PATH,要用全路径或先 Set-Alias
