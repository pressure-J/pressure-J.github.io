数字串处理技巧（CTF）

Python 2026-09-07 1095 字 约 3 分钟
pythonctf

问题：一串数字，怎么高效处理？

题目常给一长串数字，如 83 89 78 84 ...。很多人第一反应是手动加逗号拼成 Python 列表：

nums = [83, 89, 78, 84, ...]   # 手动加逗号，又慢又容易错

不需要。 数字之间是空格（或换行）分隔，直接 split() 拆：

s = input().strip()                       # 粘贴原串，空格分隔
nums = list(map(int, s.split()))          # split() 自动按空白拆，无需逗号
print(''.join(chr(n - 13) for n in nums))

一行版（比赛直接抄）

py -c "import sys; s=sys.stdin.read().split(); print(''.join(chr(int(x)-13) for x in s))"

粘贴数字串回车即出明文。

  • input().split()：按空格/换行/制表符自动拆，不用管分隔符。
  • map(int, ...)：把字符串转 int。
  • chr(n)：int 转 ASCII 字符。

核心思路：先找规律，再想怎么解析

这类题常见规律：每个数字 = 明文字符的 ASCII 码 + 一个常数（对字母就是 ROT13，但对所有字符都加同一个数）。

例：83 89 78 84 是 FLAG 每个字符 +13：

  • F(70)+13=83、L(76)+13=89、A(65)+13=78、G(71)+13=84

所以每个数减 13 再转 ASCII 即可解出。解题时先试减 13 / 加 13（ROT13 常见），看是否拼出可读 flag。

坑：CyberChef 不适合"每个数减常数"

CyberChef 没有"给列表中每个数加/减一个常数"的操作（官方 issue #1129 一直没做）。Subtract/Sum 等都是对列表内部求差，且多数模块假定输入是 ASCII。

  • 想用 CyberChef 只能绕：Fork(按空格拆) → Find/Replace 给每个数尾接 ,13 → Subtract(逗号) → From Decimal。别扭，比赛不推荐。
  • 直接用 Python 一行更快更稳。

经验

  1. 遇到一串数字，先看是否空格/换行分隔，是就用 input().split()，别手动加逗号。
  2. 数字题先猜规律：±13（ROT13）、ASCII、XOR、base 等。
  3. 若明文是 flag{...}，解出形如 flag{xxx******xxx} 的掩码 flag，解出即真 flag，别当假货。
