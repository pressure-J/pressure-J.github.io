恶意程序应急响应

应急响应 2026-07-09 1634 字 约 4 分钟
应急响应恶意程序取证

概述

当无法在线排查时（如拿到磁盘镜像或内存 dump），需要在离线环境下分析恶意程序。本文覆盖 Linux 和 Windows 两个平台的离线应急响应方法。

核心原则

只读挂载防污染，Strings 全局搜 Key，Dump 内存找痕迹，Hash 计算验真身。

一、Linux 离线分析

1.1 挂载磁盘镜像

# 只读挂载（防止污染证据）
mount -o ro disk.img /mnt

# 如果是 LVM 分区
losetup -fP disk.img
vgchange -ay
mount /dev/vg0/root /mnt

1.2 恶意程序哈希

sha256sum /mnt/path/to/malware
md5sum /mnt/tmp/.elf
# 对比 VirusTotal 哈希库

1.3 连接密码/密钥提取

# WebShell 密码
grep -r 'eval|base64|assert|system' /mnt/var/www/

# 内存 dump 中搜密钥
strings mem.raw | grep -i 'key|pass|cmd|token'

# 历史命令
cat /mnt/root/.bash_history
cat /mnt/home/*/.bash_history

1.4 持久化排查

# 定时任务
cat /mnt/etc/crontab
ls -la /mnt/var/spool/cron/
ls -la /mnt/etc/cron.d/

# 启动服务
ls -la /mnt/etc/systemd/system/
ls -la /mnt/etc/rc*.d/

# SSH 后门
cat /mnt/root/.ssh/authorized_keys

# 异常用户
cat /mnt/etc/passwd
cat /mnt/etc/shadow

1.5 隐藏文件恢复

# foremost 恢复删除文件
foremost -i disk.img -o out/

# 搜索隐藏文件
find /mnt -name ".*" -type f

二、Windows 离线分析

2.1 挂载镜像

guestmount -a disk.vmdk -i --ro /mnt

2.2 恶意程序哈希

sha256sum /mnt/Windows/System32/evil.exe

2.3 持久化排查

# 启动项
ls -la /mnt/Windows/System32/Tasks/

# 注册表 Run 键值
# Microsoft\Windows\CurrentVersion\Run

2.4 行为痕迹

# Prefetch（程序执行记录）
PECmd.exe -f 'X:\Windows\Prefetch\*.pf'

# 事件日志
evtx_dump -o json Security.evtx

三、通用离线神技

场景 命令
搜字符串 strings -el file
提取嵌入文件 binwalk -e file.bin
内存进程分析 volatility -f mem.raw pslist/netscan/cmdscan
文件恢复 foremost -i disk.img -o out/
时间线分析 fls -r -m '/' disk.img

四、CTF 解题套路

  1. 挂载镜像（只读！）
  2. strings 全局搜 pass/key/token/flag
  3. 排查持久化：crontab/systemd/authorized_keys/Run键
  4. 恢复删除文件：foremost + testdisk
  5. 内存取证：volatility pslist -> netscan -> cmdscan -> dumpfiles
  6. 恶意程序哈希 -> VirusTotal 查询
