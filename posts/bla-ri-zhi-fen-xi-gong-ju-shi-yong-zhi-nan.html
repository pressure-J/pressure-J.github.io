BLA日志分析工具使用指南

应急响应 2026-07-10 3145 字 约 8 分钟
工具日志分析BLA

简介

BLA 是一款开源的蓝队应急响应日志分析工具，支持自动识别多种日志格式并进行安全检测。由 Python 编写，离线可用，不上传日志。

版本: 1.5.0
安装: pip install blueteam-log-analyzer

基础用法

bla <日志文件/目录> [选项]

常用选项

选项 说明
--out <目录> 输出报告目录（自动创建）
--type <类型> 强制指定日志类型
--exit-on none 即使有告警也继续分析完
--config <文件> 指定配置文件
--rules <目录> 指定自定义规则目录
--allowlist <文件> 指定白名单文件
--exit-on error 遇到错误时退出（默认）

支持的日志类型

BLA 支持自动识别以下日志类型，也可以使用 --type 强制指定：

日志类型 自动识别 说明
Windows EVTX ✔ Windows 事件日志（.evtx）
Windows XML 安全日志 ✔ 导出的 XML 格式安全日志
Windows JSON (Winlogbeat) ✔ Winlogbeat/Elastic 的 JSON 输出
Linux auth.log ✔ 认证日志
Linux secure ✔ CentOS/RHEL 安全日志
Apache access.log ✔ Apache Web 访问日志
Nginx access.log ✔ Nginx Web 访问日志
Shell History ✔ .bash_history / .zsh_history
通用文本日志 ✔ 其他文本格式
CSV 文件 ✔ 逗号分隔格式
JSON 文件 ✔ JSON 格式
EDR Excel 导出 --type edr-xlsx EDR 导出的 xlsx 进程事件

实际场景用法

1. Windows 安全日志分析（EVTX/XML）

# 分析 EVTX 文件
bla security.evtx --out report/

# 分析 XML 格式（如之前分析的 RDP 暴力破解题）
bla Security_log.xml --out rdp_report/ --exit-on none

自动检测项：
- RDP 暴力破解（4625 失败登录）
- 成功登录（4624）
- 账户创建/删除
- 特权使用
- 服务安装
- 计划任务创建

2. Web 日志分析

# Apache 日志
bla access.log --out web_report/ --exit-on none

# Nginx 日志
bla nginx-access.log --out web_report/ --exit-on none

自动检测项：
- SQL 注入尝试
- XSS 攻击
- 路径遍历
- WebShell 访问
- 扫描器特征
- 异常 User-Agent

3. Linux 系统日志分析

# auth.log（Debian/Ubuntu）
bla /var/log/auth.log --out linux_report/

# secure（CentOS/RHEL）
bla /var/log/secure --out linux_report/

自动检测项：
- SSH 暴力破解
- 异常登录时间
- sudo 提权
- 用户创建/删除
- 可疑命令执行

4. Shell 历史记录分析

# 分析用户操作历史
bla .bash_history --out history_report/

# 分析 root 历史
bla /root/.bash_history --out root_history/

自动检测项：
- 明文密码输入
- 反弹 Shell 命令
- 数据外传命令（scp, rsync, curl 等）
- 恶意文件下载（wget, curl）
- 权限提升操作

输出报告结构

执行 bla 日志文件 --out report/ 后，会在 report/ 目录生成：

report/
├── report.html        # 主报告（HTML，离线可用）
├── report.json        # 详细告警 JSON
├── report.csv         # 告警 CSV
├── ioc.csv            # IOC 列表
├── report.sarif       # SARIF 格式
├── manifest.json      # 分析清单
└── assets/            # 报告资源文件

查看报告

# 直接在浏览器打开
start report/report.html

高级用法

分析整个目录

# 递归分析目录下所有日志
bla logs/ --out report/ --exit-on none

批量分析多个日志

# 同时分析多个日志文件
bla security.evtx access.log auth.log --out combined_report/

自定义白名单

# 创建白名单文件 allowlist.txt，排除已知正常 IP
192.168.1.1
10.0.0.0/8

# 运行
bla access.log --out report/ --allowlist allowlist.txt

远端工作区（只读）

# 通过 SSH 分析远程日志（只读，不传输）
bla ssh://user@host/var/log/auth.log --out report/

检测规则覆盖

BLA 内置的检测规则涵盖以下攻击类型：

类别 检测项
暴力破解 SSH/RDP/FTP 爆破、Web 登录爆破
Web 攻击 SQL 注入、XSS、路径遍历、文件包含、命令注入
权限提升 sudo 滥用、SUID 提权、令牌窃取
持久化 计划任务、启动项、服务创建、注册表劫持
横向移动 PsExec、WMI、RDP、SMB
数据外传 DNS 隧道、ICMP 隧道、大文件外传
防御规避 日志清理、进程隐藏、AMSI 绕过
凭据访问 Mimikatz、LSASS dump、DPAPI
C2 通信 Beacon 心跳、DNS over HTTPS、域前置

实际应用：验证 CTF 题目

可以用 BLA 快速验证之前做过的题目：

# 1. SSH 暴力破解题
bla combined.log --out ssh_report/ --exit-on none

# 2. RDP 暴力破解题
bla Security_log.xml --out rdp_report/ --exit-on none

# 3. SQL 注入题
bla access.log --out sqli_report/ --exit-on none

对比 BLA 自动检测的结果和手动分析的结果，可以快速确认是否遗漏了关键线索。

注意事项

  1. 离线安全：BLA 默认不联网，日志数据不会外传
  2. 性能：大日志文件（>1GB）建议分片或使用 --exit-on error
  3. 编码：Windows 下如果有中文日志乱码，先转 UTF-8
  4. 权限：分析系统日志可能需要管理员权限
  5. 规则更新：pip install --upgrade blueteam-log-analyzer 更新规则库
