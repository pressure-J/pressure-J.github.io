流密码密钥重用

密码学 2026-09-09 1279 字 约 3 分钟
crypto

题型识别（一眼看出）

  • 给了一对「已知明文 + 对应密文」（如题目说明文、或能猜到是 flag{...}）
  • 外加另一段用同一密钥加密的密文（flag 密文）
  • 出题脚本形如：
ks = os.urandom(N)                    # 一段随机密钥流
c1 = xor(known_plain, ks)             # 已知明文的密文（题目会给你）
c2 = xor(flag,        ks)             # flag 密文（题目会给你）

本质：密钥流只生成了一次、却被重复使用加密多段明文 → 任取一组明密文对就能反推密钥流。

攻击条件

  • 至少一组已知明密文对（明文长度≥想要还原的长度即可）
  • 两段密文用的是同一段密钥流

原理推导

异或运算可逆且对称：

$$c_1 = m_1 \oplus ks \Rightarrow ks = m_1 \oplus c_1$$

$$flag = c_2 \oplus ks = c_2 \oplus m_1 \oplus c_1$$

拿到密钥流后，把 flag 密文直接异或回去就是明文，不需要知道任何关于密钥流来源的信息。

解题脚本

见 ~/tools\CTF工具箱\crypto\18-流密码密钥重用-已知明密文对.py（工具箱版，已按本题写好输入解析；本目录暂无同名 solve.py）

# 只改顶部三行：
KNOWN_PLAIN  = "..."   # 已知明文（可照抄题目给的）
KNOWN_CIPHER = "..."   # 与之对应的密文
FLAG_CIPHER  = "..."   # flag 的密文
# 输入支持：纯 hex / 带空格 hex / 0x 或 \x 前缀 / 直接明文文本

ks = xor(known_plain, known_cipher)     # 密钥流 = 明文 ⊕ 密文
flag = xor(flag_cipher, ks)             # flag = 密文 ⊕ 密钥流

运行 py 18-流密码密钥重用-已知明密文对.py，自动打印还原结果。

易错点与注意

  1. 密钥流长度有限：密钥流多长就只能还原多长。flag 密文比已知明文长时，只能还原前 N 字节，剩余部分另想办法（找更多明密文对拼接密钥流 / 爆破剩余字节）
  2. 明文密文要一一对应：同一段的明文和密文对不齐，推导出的密钥流就是错的
  3. 区分 OTP 与流密码：严格一次性密钥（OTP）密钥不重用就没法打；此题能做是因为密钥被重用了——看到"同一密钥加密多段"就是信号
  4. 常用于 RC4 类：RC4 的密钥流由密钥 KSA/PRGA 生成，若同一 key 加密多条消息即密钥流重用，同法可破

实战记录

  • 题型：已知明文 flag{this_is_a_known_plaintext_for_test} + 其密文，求另一段 flag 密文
  • 推导密钥流 ba0bc0fe6bc0f860...（40 字节）后还原 flag{reused_keystream_leaks_everything}
  • 提示：若题目只给"已知某明文"而不给密文，需结合另一段密文猜——密钥流可通过 c1 ⊕ c2 抵消（明文已知时）
