技术栈与项目开发基础知识

基础 2026-08-31 2148 字 约 6 分钟

一、什么是技术栈？

技术栈（Tech Stack）＝ 构建一个项目时用到的所有技术工具的集合。可以理解为"这个项目是用什么做出来的"完整清单——编程语言、框架、数据库、服务器、第三方服务加起来，就是它的技术栈。

分层视角

层次 作用 常见例子
编程语言 底层基础，决定怎么写代码 Python、Java、Go、JavaScript
框架 / 库 在语言之上快速搭建功能 FastAPI、Django、React、Flask
数据库 存储数据 MySQL、PostgreSQL、SQLite、Redis
服务器 / 部署 让项目运行并对外提供服务 Nginx、Docker、云服务器
第三方服务 外部能力（AI 大模型、支付、短信等） DeepSeek API、微信支付、阿里云 OSS

一句话：技术栈 = 做一道菜用到的所有食材和厨具。

二、常见技术栈举例

1. Web 后端（最典型）

语言：Python / Java / Go / Node.js
框架：FastAPI / Spring Boot / Gin / Express
数据库：MySQL + Redis
部署：Docker + Nginx + 云服务器

2. Web 前端

语言：JavaScript / TypeScript
框架：Vue / React
构建工具：Vite / Webpack
样式：Tailwind CSS / Element Plus

3. 全栈（一个人全包时）

前端：Vue3 + Vite
后端：Python + FastAPI
数据库：SQLite 起步，量大换 MySQL
部署：前后端分离，Nginx 反向代理

4. 安全方向示例

做漏洞扫描/渗透测试工具：
语言：Python
库：requests、scapy、pycryptodome
框架（可选）：FastAPI 做 Web 化界面

三、我的项目：CyberStrikeAI 技术栈

项目定位：CTF 自动化解题 Agent（用户负责 Agent 核心 + Crypto 工具）

编程语言：Python 3
Web 框架：FastAPI（提供 API 接口，处理 HTTP 请求）
AI 能力：DeepSeek / mimo LLM（理解题目、生成解题思路）
加密工具：pycryptodome / sympy（Crypto 方向工具）
协作：Git + GitHub（同学共同开发）

为什么这么选？（选型依据，面试必问）

选型 理由
Python 生态丰富：AI SDK、密码库、网络库齐全；CTF 圈和 AI 圈主流语言
FastAPI 轻量、异步性能好、写 API 快、自动生成接口文档（/docs）；比 Django 更适合工具型项目
DeepSeek API 国内直连、API 便宜、中文理解好，学生项目友好
SQLite / 不用复杂库 工具型项目数据量小，避免过度设计

四、为什么技术栈重要？

  1. 招聘 JD 必写：岗位要求常见"熟悉 XX 技术栈"，如"熟悉 Python + FastAPI + MySQL"
  2. 项目介绍的固定开头：面试官第一句通常是"你们项目用的什么技术栈？"
  3. 简历标准格式：项目标题下写 技术栈：Python、FastAPI、DeepSeek API，HR 一眼扫清
  4. 技术选型体现水平：能解释"为什么选 A 不选 B"，是区分新手和进阶的加分点

简历写法示例

CyberStrikeAI - CTF 自动化解题 Agent
技术栈：Python 3 / FastAPI / DeepSeek API / pycryptodome

五、如何快速看懂一个项目的技术栈？

拿到一个陌生项目（GitHub 仓库），按顺序看：

  1. README.md → 通常写明了技术栈和启动方式
  2. requirements.txt / pyproject.toml（Python）→ 依赖清单即技术栈
  3. package.json（前端）→ dependencies 字段
  4. Dockerfile / docker-compose.yml → 运行环境用的东西
  5. 项目根目录结构 → 前端/后端/数据库目录分得越清，技术栈越好辨认
# Python 项目一条命令看依赖
pip list

# 或看项目的依赖声明文件
cat requirements.txt

六、常见问题

1. 技术栈和"框架"有什么区别？

框架只是技术栈的一层。技术栈是全部（语言+框架+数据库+部署），框架只是其中一层。

2. 需要精通每一层吗？

不需要。求职时精通 1-2 层 + 了解其他层即可。比如后端岗位：精 Python + FastAPI，知道 MySQL、Docker 怎么用即可。

3. 学新东西怎么往技术栈里加？

做新项目时刻意使用：比如给 CyberStrikeAI 加 Redis 缓存，学完直接写进项目 README，技术栈就"更新"了——技术栈是随着项目成长积累出来的。
